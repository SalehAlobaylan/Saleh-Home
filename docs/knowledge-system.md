# Knowledge system

The main deliverable is a working nested Obsidian vault at `knowledge-vault/`. Its shallow folders are `inbox/`, `notes/`, `maps/`, `templates/`, and `attachments/`. `Home.md` is private navigation; `index.md` is the explicit public landing page.

The starter includes two linked public example concepts and a private map and scratchpad. They demonstrate links and export behavior; they do not assert Saleh’s expertise. Replace or expand them as you learn.

Core Obsidian features provide templates, search, properties, backlinks, outgoing links, graph, and tags. No community plugins are required. Portable Markdown is canonical. Configuration versions only useful settings; per-device workspace state, cache, plugins, and trash are ignored.

Public/private filtering is applied before Quartz parses files. Quartz graph and backlinks therefore use only exported notes. Local Obsidian graph can include the full private vault. This is intentional.
